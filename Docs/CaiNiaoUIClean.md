# 菜鸟净化 v0.2.0

根据你提供的 `2026-09-11-202622` 抓包制作。新版已经完成真实响应的数据层修改与本地回放验证；尚未在你的手机上验收界面效果。

## 这次处理了什么

| 截图中要隐藏的位置 | 本版处理 | 验证边界 |
| --- | --- | --- |
| 底部“发现／中间入口／消息” | 从导航配置删除三个已识别的中间模块，保留“首页／我的”及其原始跳转信息 | 新抓包的中间入口叫“寄件券”，与截图中的“物换物”有差异；其他下发版本尚未验证 |
| 首页整排快捷功能 | 删除已识别的两组快捷栏，以及新人推广模块；保留搜索栏数据 | 组内取包裹、寄包裹、出库码等入口也会随整组隐藏；不修改组外入口 |
| “我的”会员、积分及资产、钱包、热门活动 | 删除对应页面模块 | 保留头像身份区、常用功能主体和订单区数据 |
| “我的”三卡片区域 | 删除包含“分享赚现金／包裹账单”的整个 packageArea 模块 | “我的包裹”卡片是否随容器一起消失，仍需手机确认 |
| 首页包裹列表下面的推广区域 | 将已识别的推广容器设为不可见，并清空其 feeds | 抓到的是推广占位结构，尚未证明客户端会收拢空白区域 |
| 顶部“去寄件／物换物”标题 | 暂未处理 | 没有找到可靠的对应布局，不用猜测字段删除 |

本版修正了上一版未覆盖的个人页接口 `.cn` 后缀。本次部分响应使用 zstd 压缩，因此增加了请求头规则，向服务器请求 gzip/deflate；服务器是否遵从以及 Quantumult X 实际解码情况，需要手机验证。收到无法解析的正文时，脚本保留原响应。

上一轮确认的两个广告素材主机与 `/ad.union.api/` 路径拦截继续保留作为补充。这条规则匹配上一轮 12 个请求，本轮没有命中；它按主机与路径生效，其他 App 使用相同素材地址也会受到影响，不能视为仅针对菜鸟的规则。

## 加入原配置

在正在使用的配置的 `[rewrite_remote]` 区段加入下面这一行，不要重复添加区段标题：

```ini
https://raw.githubusercontent.com/belcheckyoung/Belcheck-QX-AdBlock/main/Rewrite/CaiNiaoUIClean.snippet, tag=菜鸟界面与广告净化, update-interval=86400, opt-parser=false, enabled=true
```

订阅内含请求头处理、响应净化、广告素材拦截，以及所需 MITM 主机。脚本自动远程加载，无需在手机保存 JS。不要将这行加进 `[filter_remote]`。

保存后手动更新该远程重写，确保重写和 MITM 已开启、证书已经安装并信任，再完全退出菜鸟并重开，刷新首页和“我的”。导航可能使用缓存，一次重开不一定重新下发。

若已经安装本地 v0.1 / v0.2，请删除或注释掉对应的三条本地重写；同时停用其他改写相同菜鸟接口的旧版菜鸟净化订阅，避免重复修改。无需删除本地证书，也不要覆盖原有 hostname 列表。其他软件的规则保持原样。

本订阅只补充菜鸟净化，不替换整份私人配置，也不改变现有分流和节点。

## 手机验收重点

- 底部能否只显示“首页／我的”，两个入口能否正常切换，有无空白或点击错位。
- 首页快捷栏、下方推广区域以及“我的”红框内容是否消失，有无残留占位。
- 包裹列表与物流详情、搜索及添加包裹、顶部扫码／出库码是否正常；保留的客服、地址簿和订单入口能否打开。

如果只剩空白框，仍属于未完成的界面净化。请保留当时页面截图；已有本地验证不能代替这一步。

## 回退或单独关闭

将这条订阅的 `enabled=true` 改为 `enabled=false` 并保存，即可停用；也可以删除该订阅行。若此前停用了其他菜鸟模块，可按需恢复。无需卸载菜鸟或删除数据。

脚本有四个独立开关。需要只关闭某一类清理时，可将脚本与规则改为自用版本再调整开关；直接编辑手机上的远程缓存可能被后续更新覆盖。
